### Сделано

- [x] **Запрос одного правила.** `GET /api/rules/{id}` и фильтр `legal_act_id` у `GET /api/rules`. Страницы
  правила и НПА и правила без нарушений на экране аудита больше не загружают весь список правил.

- [x] **Экспорт отчёта (FR-4.4).** `GET /api/reports/{id}/export?format=html` отдаёт отчёт одним
  HTML-файлом. PDF и DOCX с комментариями перенесены в диплом, см. [`DIPLOMA.md`](DIPLOMA.md).
- [x] **Текст документа в API.** `GET /api/documents/{id}` отдаёт поле `text`, смещения нарушений
  указывают на него.
- [x] **Связь нарушения с пояснением и нормой (FR-4.3).** В нарушении есть `finding_key`, `rule_code`,
  `rule_name`, `legal_act_code`, `legal_act_title` и `norm_quote`. Они хранятся в отчёте и доступны
  после удаления правила или акта.
- [x] **Редактирование правил (FR-5.2).** `PATCH /api/rules/{id}` меняет название, описание, важность,
  тип проверки, параметры и `is_active`.
- [x] **Удаление документа.** `DELETE /api/documents/{id}` удаляет документ, его отчёты и файл.
- [x] **Мелочи.** `GET /api/reports/{id}`, `PATCH /api/document-types/{code}`, заголовок `X-Total-Count`
  у постраничных списков, фильтр правил `applicability_scope`.
- [x] **Правила `semantic`.** Модель не может их создать, а API отклоняет такие правила при создании и
  редактировании (`422 unsupported_check_type`).
- [x] **Важность нарушений.** Модель выбирает её по заданным критериям при температуре 0: на трёх
  примерах НПА три запуска дали одинаковый результат. Человек может изменить важность вручную.
- [x] **Ошибки API.** Нельзя очистить обязательные поля НПА, совпадающий код НПА даёт `409`, при смене
  текста статус становится `needs_reprocessing`, неверные параметры правила и пустые файлы
  отклоняются, `title` читается из формы, файлы НПА не остаются на диске, формат ошибок единый.
- [x] **Запись в базу во время аудита.** Транзакции больше не открыты на время вызовов моделей.
- [x] **Ложные нарушения в правилах срока и числа.** Модель подтверждает каждое такое нарушение по
  норме и окружающему тексту, в том же запросе, что и пояснение. Отклонённые кандидаты сохраняются в
  `summary.rejected_candidates`.
- [x] **Дата принималась за срок.** «5 числа следующего месяца» больше не считается сроком.
- [x] **Ошибочный пример** `compliant_remote_work_agreement.txt` исправлен.
- [x] **Тесты на настоящих ответах модели:** `tests/fixtures/recorded_gemini_audit.json`.
- [x] **Ссылки на НПА в пояснениях.** Их формирует сервер из правила, модель на них не влияет.
- [x] **Язык пояснений** теперь совпадает с языком документа.
- [x] **Таймаут Google-клиента.** Таймаут берётся из профиля модели, при его истечении API отвечает
  `504 model_timeout`.
- [x] **Загрузка НПА не блокирует сервер.** Обработка вынесена в пул потоков. Загрузка НПА и аудит
  остаются одним долгим запросом без прогресса: на маленьких файлах этого достаточно.
- [x] **Отдельная ошибка при превышении лимита модели.** API отвечает `429 model_rate_limited`, и
  фронт может предложить повторить действие позже.

## Отложено

- **Повторная обработка НПА** пересоздаёт его правила, поэтому ручные правки этих правил, включая
  `is_active` и применимость, теряются.
- **Большие НПА** вроде Трудового кодекса: один неудачный фрагмент останавливает публикацию всех
  правил акта, а число запросов быстро превышает лимит модели.
- **`alembic.ini`:** путь к базе задан жёстко, поэтому миграции всегда идут в
  `data/edm_auditor.sqlite3`.
- **Порог уверенности 0.7:** проверен только на нескольких примерах.
