## 1. Доработка бэкенда

- [x] **Таймаут Google-клиента.** Таймаут берётся из профиля модели, при его истечении API отвечает
  `504 model_timeout`.
- [x] **Загрузка НПА не блокирует сервер.** Обработка вынесена в пул потоков. Загрузка НПА и аудит
  остаются одним долгим запросом без прогресса: на маленьких файлах этого достаточно.
- [x] **Отдельная ошибка при превышении лимита модели.** API отвечает `429 model_rate_limited`, и
  фронт может предложить повторить действие позже.

## Отложено

- **Большие НПА** вроде Трудового кодекса: один неудачный фрагмент останавливает публикацию всех
  правил акта, а число запросов быстро превышает лимит модели.
- **Правила типа `semantic`:** через API они пока не выполняются.
- **`alembic.ini`:** путь к базе задан жёстко, поэтому миграции всегда идут в
  `data/edm_auditor.sqlite3`.
- **Порог уверенности 0.7:** проверен только на нескольких примерах.
